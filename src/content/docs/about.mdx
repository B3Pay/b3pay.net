## Where we come from

B3Pay started in 2023 with B3Wallet, a self-custodial wallet canister on the Internet Computer, and grew into libraries other teams depend on: IC Reactor for typed canister calls in TypeScript and React, and Meant, which compiles Candid interfaces into a canonical graph that says what each value means and what each call does.

The same question ran through all of it: what exactly is this call about to do? In 2026 we turned that question to EVM, where ERC-7730 now gives wallets a shared way to answer it.

| Year | |
| ---- | --- |
| 2023 | B3Wallet: a multi-chain, multi-owner wallet canister |
| 2023 | B3Note: an encryption demo on vetKeys |
| 2024 | IC Reactor reaches seven packages |
| 2025 | B3Forge enters beta: workflows that run in the browser |
| 2026 | EVM first: Clear Signing descriptors and tooling for agents |

## How we work

- **Fail closed.** A check that cannot explain something refuses it instead of guessing.
- **Official tooling first.** We build on the standards' own tools, such as python-erc7730 and Sourcify, instead of rewriting them.
- **No keys, ever.** Nothing we make asks for a private key or a seed phrase, and nothing it builds sends a transaction a person has not read and approved.
- **In the open.** Our libraries are open source on [GitHub](https://github.com/B3Pay).
