## How these docs are made

Each product's docs live in its own repository and are published here as a module. The site checks every module before it serves it, and [`/modules.json`](/modules.json) lists which commit of each repository is live. To publish a module from a repository, see [the module guide](https://github.com/B3Pay/b3pay.net/blob/main/modules/README.md).
