## Blind signing is the gap

When a wallet can't read a contract call, it shows the person signing a string of hex and asks them to trust it. ERC-7730 closes that gap: a JSON descriptor tells a wallet how to turn a call into a sentence, with every value labeled and formatted. Since 12 May 2026 the standard has a registry hosted by the Ethereum Foundation and a framework for independent reviewers to attest descriptors. A wallet that supports it can show your users what they are signing, but only once a descriptor for your contract is in a registry it reads.

<p class="sourced">Sources, checked 30 October 2026: the [Ethereum Foundation's announcement](https://blog.ethereum.org/2026/05/12/clear-signing-announcement) and [ethereum.org's Clear Signing guide](https://ethereum.org/developers/tutorials/clear-signing).</p>

## One descriptor, two readers

The descriptor we write so a wallet can show a person what a call does is the same file our toolkit turns into an agent's tool for that call, with the same readable text as its consent message. An agent working through it can only propose calls the descriptor explains, and a person reads each one before it is signed.
